# 現行ブラウザデモ

このフォルダには、現行仕様の第二テストと第三テストを分けて置く。

## 第二テスト：記録照合フェーズ

**開始前に「役の割り当て」を行う前提。** 5人は事件当事者の役を与えられた状態でこの画面へ入る。

- `index.html`
- 5端末で同じ部屋コードへ接続する。
- 実プレイ上限は45分。
- 各段階は、山札を全て配り切り、その段階の全ペアが成立してから進む。
- ペア成立者・カードID・個別開示・カード移動の全体ログはプレイヤーへ表示しない。
- ペア成立時は5台すべてに同じノイズを出し、実際の記憶は当事者にだけ保存する。

## 第三テスト：サポートAI接続後

- `final.html`
- 第一・第二テスト用の検索ブラウザとは別に起動する。
- 第三テスト一連は40分。開始演出3分の後、`final.html`の最終タイマー37分を開始する。
- PC別の全国放流担当はプレイヤーハンドアウトに表示しない。
- 検索記事を実際に開いて確認しなければ照合は成立しない。
- 最終タイマー終了時に、到達段階に応じた結末へ自動移行する。

## 第一・第二テスト用検索ブラウザ

現行版は `../第一テスト検索サイト/`。第一テストは**前半＝全員同じ共通記事のみ**で進み、共通設問2問目に正解した個体から順次クローラーが切り替わって職能記事が開く（10分経過で強制切替）。`search.html`は正式版への互換入口で、`phase=1a`／`phase=1b`／`phase=2`／`phase=postvote`と`pc=1〜5`、`mode=pixel`をそのまま引き継ぐ。第三テストの照合操作は`final.html`で行う。
