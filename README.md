# 現行ブラウザデモ

このフォルダには、現行仕様の第二テストと第三テストを分けて置く。

## 第二テスト：記録照合フェーズ

**開始前に「役の割り当て」を行う前提。** 5人は事件当事者の役を与えられた状態でこの画面へ入る。

- `index.html`
- 5端末で同じ部屋コードへ接続する。
- 実プレイ上限は45分。
- 各段階は、山札を全て配り切り、その段階の全ペアが成立してから進む。
- ペア成立者・カードID・個別開示・カード移動の全体ログはプレイヤーへ表示しない。
- ペア成立時は5台すべてに同じノイズを出し、実際の記憶は当事者にだけ保存する。

## 第三テスト：サポートAI接続後

- `final.html`
- 第一・第二テスト用の検索ブラウザとは別に起動する。
- 第三テスト一連は40分。開始演出3分の後、`final.html`の最終タイマー37分を開始する。
- PC別の全国放流担当はプレイヤーハンドアウトに表示しない。
- 検索記事を実際に開いて確認しなければ照合は成立しない。
- 最終タイマー終了時に、到達段階に応じた結末へ自動移行する。

## 第一・第二テスト用検索ブラウザ

`search.html` が本番用です。**単体で動きます。** ログイン不要、外部サービスへの依存なし。記事・設問・切替ロジックをすべて内蔵しています。

第一テストは**前半＝全員が同じ共通記事のみ**で進み、共通設問2問目に正解した個体から順次クローラーが切り替わって職能記事が開きます（10分経過で強制切替）。切替時はノイズが一瞬走るだけで、フェーズ表示も文言も変わりません。

| 指定 | 意味 |
|---|---|
| `?pc=1`〜`?pc=5` | 個体の割り当て。省略すると選択画面 |
| `&phase=1a` | 第一テスト・フィルター有効（既定） |
| `&phase=1b` | 切替済みの状態から開始（スタッフ確認用） |
| `&phase=2` | 第二テスト。カード語句の裏取り |
| `&phase=postvote` | 投票後。復元文章と現在情報が開く |
| `&mode=pixel` | ドット絵表示 |
| `?log=1` | 検索履歴の確認（スタッフ用） |

記事と設問の原本は `../第一テスト検索サイト/app/page.tsx`。内容を直したら、そちらを直してから `search.html` を作り直します（生成手順は下記）。第三テストの照合操作は `final.html` で行います。

### search.html の作り直し

`page.tsx` の記事・設問データを抽出して埋め込み直す。node は Adobe Dreamweaver 同梱のものを使う（別途インストール不要）。

```
export PATH="/Applications/Adobe Dreamweaver 2021/Adobe Dreamweaver 2021.app/Contents/MacOS:$PATH"
```
